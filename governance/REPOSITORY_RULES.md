# Repository Rules

**ID:** NVIDIA-GOV-RULES-001  
**Version:** 0.1

1. **Source fidelity** — explanations based on external documentation preserve source and consultation context.
2. **Separation of concerns** — distinguish source material, interpretation, experiments and results.
3. **Progressive learning** — labs use L0 Concept, L1 Beginner, L2 Intermediate, L3 Advanced.
4. **Reproducibility** — labs declare objective, requirements, configuration, steps, expected/actual result, errors and cleanup.
5. **Versioning** — material conceptual changes require version review or ADR.
6. **Inventory gate** — an artifact is not integrated until registered in the artifact inventory.
7. **Security** — never commit keys, tokens, credentials, secrets or private data.
8. **Evidence gate** — a claim that a lab works requires reproducible evidence.
9. **Certification mapping** — certification-relevant concepts map to a competency/domain once the current official blueprint is verified.
10. **Agent behavior** — prefer small, traceable, reviewable changes.
