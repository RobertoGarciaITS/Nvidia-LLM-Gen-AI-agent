# Documentation Lifecycle

**ID:** NVIDIA-DOC-LIFECYCLE-001  
**Version:** 0.1

```
PLANNED → DRAFT → REVIEWED → VALIDATED → SUPERSEDED / ARCHIVED
```

## Definition of Done
A document can become VALIDATED when it has objective and scope, identified sources, facts separated from interpretation, sufficient examples, known dependencies, reviewed/executed code where applicable, and an updated inventory entry.

## Versioning
- `v0.x`: evolving learning/design.
- `v1.0`: stabilized and validated.
- `v1.x`: compatible improvements.
- `v2.0+`: significant conceptual change.
