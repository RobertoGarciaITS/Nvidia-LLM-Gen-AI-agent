# NVIDIA LLM / GenAI Agent Learning Repository

Repositorio de aprendizaje, laboratorio, configuración y evidencia para estudiar NVIDIA Generative AI, LLMs y agentes de IA, con énfasis en NeMoClaw/OpenClaw, RAG, workflows de agentes y preparación para certificación.

## Objetivos

1. Convertir el aprendizaje en conocimiento versionado y trazable.
2. Mantener un inventario de documentos, contratos, labs, código y evidencias.
3. Aprender a configurar y evaluar agentes de IA de forma progresiva.
4. Separar teoría, laboratorio, código, gobernanza y evidencia.
5. Preparar material reutilizable para certificación y evaluación práctica.

## Estructura

- `inventory/` — registro maestro de artefactos.
- `governance/` — contratos, políticas, reglas y ADRs.
- `docs/` — conocimiento, guías y notas.
- `agents/` — configuración conceptual y técnica de agentes.
- `labs/` — ejercicios reproducibles.
- `src/` — código reutilizable promovido desde labs.
- `tests/` — pruebas.
- `evidence/` — resultados y evidencia.
- `certification/` — preparación para certificación.
- `references/` — fuentes externas.

## Ciclo operativo

```
SOURCE → LEARN → DOCUMENT → LAB → TEST → EVIDENCE → REVIEW → INVENTORY
```

El repositorio funciona como memoria externa versionada del proyecto. Los agentes deben adquirir contexto desde `AGENTS.md`, el inventario y las reglas antes de realizar cambios.
