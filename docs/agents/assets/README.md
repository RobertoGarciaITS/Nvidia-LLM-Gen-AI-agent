## Project resolution policy

```text
PREVIEW        512 × 341
DOCUMENTATION 1024 × 682
MASTER        2048 × 1364
```

Aspect ratio, layout and semantics are locked.

Current 512 × 341 images remain the canonical raster baselines until a controlled higher-resolution master or editable/vector source is approved.
