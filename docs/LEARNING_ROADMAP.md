# Learning Roadmap — NVIDIA LLM / GenAI Agent

## Goal
Progressively learn to understand, configure, build, test and explain AI agents with NVIDIA technologies while using this repository as study memory and lab evidence.

## Phase 0 — Foundations
LLM basics; prompt/context/tool/memory; inference vs training; tokens/context/sampling; agent loop; tool calling; state and memory.

**Exit:** explain a minimal agent without relying on a framework.

## Phase 1 — NVIDIA ecosystem
NVIDIA NIM; NeMo ecosystem; NeMoClaw/OpenClaw; model endpoints; guardrails; RAG; observability.

**Exit:** explain the role and boundaries of each major component.

## Phase 2 — Agent configuration
```
Agent
├── model
├── instructions
├── tools
├── context
├── state
├── memory
├── retrieval
├── guardrails
└── evaluation
```

**Exit:** configure and explain a minimal agent.

## Phase 3 — Labs
Deterministic tool agent; RAG agent; multi-tool agent; workflow/state agent; evaluation lab; failure/recovery lab.

## Phase 4 — Certification preparation
```
CONCEPT → DEFINITION → EXAMPLE → LAB → QUIZ → FAILURE MODE → EVIDENCE
```

A certification matrix will be created only after verifying the current NVIDIA certification and official blueprint.
