# Labs

Labs convert theory into evidence.

## Standard lab contract
```
LAB-ID
objective
level
concepts
preconditions
dependencies
configuration
steps
expected_result
actual_result
tests
common_errors
lessons_learned
cleanup
references
```

## Initial sequence
1. LAB-001 — Minimal agent loop.
2. LAB-002 — Model configuration.
3. LAB-003 — Tool definition and invocation.
4. LAB-004 — Context injection.
5. LAB-005 — State and memory.
6. LAB-006 — Retrieval / RAG.
7. LAB-007 — Guardrails.
8. LAB-008 — Evaluation and observability.

Labs may start as notebooks or simple Python. Reusable components are promoted to `src/` only after validation.
